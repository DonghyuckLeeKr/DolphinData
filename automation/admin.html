앱의 ‘문제 접수’로 보낸 기록이 아래 목록과 디스코드에 표시됩니다. 백업 JSON도 가져올 수 있습니다. 자동 수정 요청 시 문제 설명과 익명화한 기록을 AI가 분석합니다. 문제 설명은 공개 GitHub에 올리지 않습니다.

관리자 연결을 준비하고 있습니다. 이 안내가 계속 보이면 automation 폴더의 Start-Automation.cmd를 실행하고 열린 브라우저를 사용해주세요. HTML 파일 미리보기에서는 접수 목록을 불러올 수 없습니다.
